# Auto Connect Mali

Application Flutter de mise en relation avec des prestataires automobiles au Mali.

## Fonctionnalites

- Recherche de garages, vendeurs de pieces, pneumatiques et autres services.
- Filtres par ville, statut ouvert et tri par note, nom ou distance.
- Carte Google Maps et liste des prestataires a proximite.
- Espace professionnel pour ajouter, modifier et gerer ses services.
- Favoris, avis clients, appel telephonique et partage de position.
- Assistance panne avec partage GPS.

## Configuration

Avant une build mobile de production, remplacez `YOUR_GOOGLE_MAPS_API_KEY`
dans les fichiers Android et iOS par une cle Google Maps valide.

## Commandes utiles

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```
